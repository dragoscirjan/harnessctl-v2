# Installable caveman and repository memory skills

As a development team
I want installable concise-communication and shared-memory skills
So that agents use fewer tokens and retain curated project knowledge safely.

## Scope

- Implement approved [LLD](../.specs/lld-00002-caveman-and-memory-skills-v1.md).
- Ship OpenCode `caveman` and repository-backed `memory` skills.
- Provide canonical Git-shareable records, normalized tools, cache, validation, and docs.

## Non-Goals

- Remote memory backends.
- Unverified Pi memory integration.
- Persisted secrets, transcripts, or chain-of-thought.

## Acceptance Criteria

- [ ] All child tasks complete in dependency order.
- [ ] Python, TypeScript, quality, and strict typecheck suites pass.
- [ ] User can install and test both skills in an OpenCode project.
