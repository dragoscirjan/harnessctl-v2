# Plan: Initiative mode

Use only for work spanning multiple independently plannable Epics.

Show Initiative boundary, outcome, non-goals, and why one Epic is insufficient. For each Epic show objective, isolated scope, acceptance direction, dependencies, order, and overlap risk. Confirm Initiative and every Epic separately before creation. Use configured issue tools; attach supported hierarchy and verify every result.

Do not design, decompose, or combine executable plans across Epics. End with one `work-plan <epic-id>` recommendation per attached Epic, then stop.
